## 📋 COMO USAR ESTE ARQUIVO

Cada **BLOCO** abaixo é um clipe do vídeo final. Dentro de cada bloco você tem:

| Passo | O que fazer |
|---|---|
| **① IMAGEM — FRAME A** | Copie o prompt e cole na sua IA de imagem. Essa imagem é o **primeiro quadro** do clipe. |
| **② IMAGEM — FRAME B / C** | Copie e cole. São os **quadros seguintes** do mesmo clipe (meio e fim). |
| **③ PROMPT DE VÍDEO** | Suba as imagens no Seedance **na ordem A → B → C** e cole este prompt. Ele diz **em que segundo cada frame aparece, o que acontece e quem fala o quê**. |

### ⚙️ Configuração no Seedance 1.5 Pro
```
Modo: Image-to-Video (I2V)     generate_audio: true
resolution: 720p → 1080p       aspect_ratio: 16:9
duração: a que está indicada em cada bloco
seed fixo: use o MESMO número em todos os clipes para manter o estilo coerente
```

### ➕ Se a sua ferramenta só aceitar 2 imagens
Use o **FRAME A** (inicial) e o **FRAME C** (final). O FRAME B vira referência de apoio: se quiser
usá-lo, gere um clipe extra e emende na edição.

### ➕ Se aceitar só 1 imagem
Use o FRAME A e escreva no prompt de vídeo os acontecimentos dos frames seguintes — eles estão
descritos em ordem na linha do tempo.

### 🗣️ Sobre a narração (a Voz de Deus)
A Voz **nunca aparece na imagem**. Nos prompts de vídeo ela está marcada como **(FORA DE QUADRO)**.
O ideal é **gravar à parte** — o texto completo de cada narração está em `roteiro/01_EP01_CRIACAO.md` —
e montar por cima na edição. Se preferir que o Seedance gere a voz, mantenha a fala entre aspas no
prompt, como está.
